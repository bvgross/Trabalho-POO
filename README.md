# Trabalho Final de programação orientada à objetos.
#### Trabalho final da matéria de programação orientada à objetos da Residência em Desenvolvimento de Software do Serratec.

### Objetivo do sistema 
Esse trabalho consiste em fazer um sistema de gerenciamento de uma academia.

- O sistema deve integrar funcionários, alunos e personal trainers da seguinte forma:

Funcionários:

- Ser capazes de inscrever alunos e personal trainers novos
- Cadastrar novos planos para a academia
- Emitir relatórios
- Emitir um faturamento mensal

Alunos:

- Visualizar seus dados e o plano contratado
- Contratar um personal trainer cadastrado
- Visualizar suas avaliações físicas

Personal Trainers:

- Visualizar sua lista de alunos
- Registrar uma nova avaliação física para um aluno seu
- Visualizar todas as avaliações realizadas


### Objetivo do trabalho
Estudar e implementar conceitos como:

- Interfaces
- Classes abstratas
- Classe concreta
- Encapsulamento
- Modificadores de Acesso
- Exceções
- Enum
- Arquivos
- As datas devem ser do tipo LocalDate
- Coleções (HashSet, ArrayList ou Map)
- Herança
- Separação por pacotes
